# Afriqo E-Learning Tanzania — Website

Marketing site for [Afriqo E-Learning Tanzania](https://www.afriqoelearningtz.com), an Arusha-based education technology company.

## Programs featured
- **SonzaSchool** — digital learning platform for Standard 1–Form 6, plus vocational
- **SonzaSpark** — practical STEM, robotics and electronics for ages 8–16
- **SonzaTech** — technology services for schools, NGOs and businesses

## Tech
- Single-file static site (`index.html`) with inline CSS
- Tailwind CSS via CDN
- Poppins (Google Fonts)
- Real brand assets in `brand_assets/`
- Program photos in `photos/`

## Local development
```bash
node serve.mjs           # serves on http://localhost:3000
node screenshot.mjs http://localhost:3000 label   # saves a full-page PNG
```

## Hosting
